# Plan 9: Evals and Agent Ops Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a valid (`summary.run_status == "OK"`) evaluation baseline over ≥ 50 verifiable curated claims. Add the DeepEval faithfulness guardrail, ADK eval over pipeline traces, and measured latency and cache figures.

**Spec:** `docs/superpowers/specs/2026-10-16-evals-design.md`. Read §2 (facts checked against code) and §6 (open decisions) first.

**Tech stack:** Python 3.12, pytest, DeepEval (`eval` dependency group), `agents-cli` (uv tool), Google ADK 2.12, Gemini (`gemini-3.1-flash-lite`), sentence-transformers, Supabase/pgvector.

## Amendments (2026-10-20 for ADK-Native Agents)

The plan was designed on 2026-10-16 before the ADK-native worker refactor (`cd69a7f`, `e518dd7`, merged 2026-10-20). The following amendments reconcile the plan with current architecture:

1. **Worker Agent Architecture:**
   - Groq `gpt-oss-120b`, LiteLLM, and leaf LLM prompts (`verdict_extractor`, `claim_aligner` via `run_adk_agent`) are removed.
   - Workers are ADK `LlmAgent`s on native Gemini (`settings.model_id = gemini-3.1-flash-lite`).
   - Agent names: `factcheck_judge`, `crossref_searcher`. Tools: `search_fact_check_sites`, `search_fact_checks`, `search_news_coverage`. Decisions are emitted via `set_model_response`.

2. **Model Seam & Transcripts (Task 4):**
   - Transcripts hook the model seam `backend/app/agents/common.py::get_model`, which is already wrapped by `EvidenceReplay` in `eval/replay.py` (`_wrap_get_model` and `ReplayLlm`, keyed by `request_key(llm_request)`).
   - Recorded transcripts represent per-agent LLM turns (prompt, tool calls, final response).

3. **Leaf Groundedness (Task 5 Step 2):**
   - Re-derive groundedness evaluation from the new agents' final decisions (`factcheck_judge` rating and explanation evaluated against the fetched page text and grounded search snippets).

4. **Roadmap R1 Evolution (Worker Agency):**
   - The LLM selects actions inside each worker bounded by per-tool call caps (db: 2, sites: 1, news: 2).
   - Deterministic components: the supervisor graph and `finalize()`.
   - Trajectory verification checks: (a) every worker executed, (b) tool-call counts remain within caps, (c) degraded workers are flagged (`degraded=True`, "Partial Analysis"), (d) bias labels come strictly from AllSides static data.

5. **Configurable Timeouts:**
   - Timeouts are configuration backstops (`settings.agent_timeout_s = 30`, `settings.request_deadline_s = 35` default). Evals pin explicit timeout settings rather than relying on environment defaults.

6. **Judge Model Selection (Decision D6):**
   - Groq is tabled. The eval judge model uses Gemini via `GEMINI_API_KEY` (e.g. `gemini-2.5-pro` or `gemini-2.5-flash` to mitigate self-judging bias vs `gemini-3.1-flash-lite`).

7. **Code Seam Updates:**
   - `_consolidate_sources` is located at `backend/app/agents/orchestrator.py:343`.
   - `settings.eval_judge_model` in `backend/app/config.py` and the `live_api` marker in `eval/conftest.py` are to be created in Task 5 and Task 1 respectively.

## Global constraints

- `uv` only (`uv add`, `uv run`). Eval-only packages go in the `eval` group, never in runtime `dependencies`.
- The scoring engine stays pure. This plan does not touch `backend/app/scoring/`.
- Bias labels come only from AllSides. Bias leakage is zero tolerance.
- Default runs are offline: replay mode for the harness, and `pytest eval/tests` makes no external calls. Anything that spends quota is a gated step that needs explicit approval from the project lead in chat.
- Nothing under `eval/` is imported by `backend/app/`.
- The run status string is `"OK"`. `STATUS_OK` is only the Python constant.

## Review focus

1. **No unrecorded call slips through replay.** A miss increments `replay.misses` and makes the run `INVALID_RUN`. It never fabricates a result.
2. **Validators are tested against real shapes.** Trace checks run on actual `verify_claim` responses, including fault-injected ones, never only on hand-written dicts.
3. **Labels are frozen before scores are seen.** The dataset commit lands before any record run. No label edits after Task 7 without a new record run and a note in the scorecard.
4. **Honest numbers.** Every published figure carries n, the run timestamp and the judge model. A missed target is reported as missed.
